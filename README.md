# Bows-PC

## Controls:
-WASD = Movement
-SPACE/LEFT CLICK = Shoot
-ESC = Pause

- Better animations across every entity
- Epic boss fight with 4 attack types and a death cutscene
- Save system
- Better sounds
- Turkish and English language support
